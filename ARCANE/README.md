# ARCANE — Geometry in Motion

เว็บร่ายรูปทรงสามมิติด้วยมือผ่านกล้อง ในธีม Geometry สีชมพูบานเย็น–ฟ้า ใช้ MediaPipe ตรวจจับมือ และ Three.js / Canvas 2D แสดงโมเดลกับพาร์ติเคิล

## ฟีเจอร์

- ลูกบาศก์ ไอโคสเฟียร์ และพีระมิด พร้อมแผ่นผลึกและแกนพลังงาน
- หมุน ย่อ–ขยาย บีบอัด ประกอบใหม่ และสลายรูปทรง
- มินิฮาร์ทเรียกหัวใจพาร์ติเคิล และสองฝ่ามือเรียกหลุมดำ
- กราฟิก 3 ระดับ โหมดตัวอย่างไม่ใช้กล้อง และข้อความข้างมือเปิด–ปิดได้
- UI รองรับมือถือและเดสก์ทอป พร้อมคู่มือในแอป

## เริ่มใช้บนเครื่อง

`dist/` คือโค้ดเว็บที่ใช้งานจริง โปรเจกต์ไม่ต้อง build หรือ install dependencies

1. แตก ZIP แล้วเปิด Terminal ในโฟลเดอร์ที่มี `dist/`
2. ใช้ Python 3 รัน:

```sh
python -m http.server 8000 --directory dist
```

3. เปิด `http://localhost:8000` แล้วเลือก **ลองเอฟเฟกต์** หรือ **เปิดกล้อง**

บน Windows ถ้าไม่มีคำสั่ง `python` ให้ใช้ `py` แทน ห้ามเปิด HTML ผ่าน `file://` เพราะโมดูลและกล้องต้องทำงานผ่านเว็บเซิร์ฟเวอร์

ต้องมีอินเทอร์เน็ตเพื่อโหลด MediaPipe, โมเดลตรวจจับมือ, Three.js และฟอนต์ ภาพกล้องประมวลผลในเบราว์เซอร์ โค้ดแอปไม่ได้อัปโหลดภาพกล้อง แต่มีการร้องขอไฟล์จาก CDN ภายนอก

## อัปโหลด GitHub Pages

1. สร้าง repository และใช้ branch `main`
2. อัปโหลด **เนื้อหาภายในโฟลเดอร์ ARCANE** ให้ `dist/`, `.github/`, `scripts/` และ `package.json` อยู่ที่ราก repository
3. ตรวจว่า `.github/workflows/pages.yml` ถูกอัปโหลดด้วย บางโปรแกรมซ่อนโฟลเดอร์ขึ้นต้นด้วยจุด
4. ไป **Settings → Pages → Source → GitHub Actions**
5. ไป **Actions → Check and deploy ARCANE → Run workflow** หรือ push โค้ดขึ้น `main`
6. เมื่อ check และ deploy ผ่าน เปิดลิงก์ใน Settings → Pages

หากอัปโหลดผ่านหน้าเว็บแล้ว `.github` ไม่ติด ให้ใช้ Add file → Create new file ตั้งชื่อ `.github/workflows/pages.yml` แล้วคัดลอกเนื้อหาจากไฟล์นี้

Workflow ตรวจ syntax และชุดทดสอบก่อน deploy; pull request ตรวจอย่างเดียว ส่วน static hosting อื่นให้ตั้งโฟลเดอร์เผยแพร่เป็น `dist` ไม่ต้องตั้ง build command หรือ environment variables

## วิธีเล่น

ซ้าย–ขวาหมายถึงมือของผู้เล่น ไม่ใช่ด้านของภาพสะท้อนบนจอ

| มือ | ท่าทาง | ผลลัพธ์ |
| --- | --- | --- |
| ขวา | ชูนิ้วชี้ | ลูกบาศก์ |
| ขวา | ชี้ + กลาง | ไอโคสเฟียร์ |
| ขวา | ชี้ + กลาง + นาง | พีระมิด |
| ขวา | กำมือ | บีบอัด |
| ขวา | ชู 1–3 นิ้วกลับ | ประกอบใหม่ |
| ขวา | แบมือค้าง | สลาย |
| ซ้าย | พับกลาง นาง ก้อย แล้วจีบโป้ง–ชี้ | ย่อ–ขยาย |
| ซ้าย | แบมือค้างแล้วค่อย ๆ เอียงฝ่ามือ | หมุน |
| ขวา | โป้ง–ชี้ไขว้เป็นมินิฮาร์ท หันหลังมือเข้ากล้อง ค้าง 3 วินาที | หัวใจพาร์ติเคิล |
| สองมือ | ฝ่ามือหันเข้าหากัน เว้นช่องกลาง ค้างประมาณ 1 วินาที | หลุมดำ |

หัวใจหมุนและย่อ–ขยายด้วยมือซ้ายได้ แต่เปลี่ยนเป็นรูปทรงอื่นไม่ได้ คลายท่าเพื่อระเบิดหัวใจ ส่วนหลุมดำจะยุบเมื่อคลายท่า ระบบยืนยันท่าก่อนสั่งงานและผ่อนปรนการตรวจจับขาดช่วงสั้น ๆ

## กราฟิก

| ระดับ | เพดาน FPS | หัวใจ | ลักษณะ |
| --- | --- | --- | --- |
| โหด | 60 | 6,000 อนุภาค | 3D และเอฟเฟกต์เต็มรูปแบบ |
| กลาง | 60 | 2,200 อนุภาค | 3D พร้อมแสง ลดเอฟเฟกต์รอบโมเดล |
| ต่ำ | 30 | 180 อนุภาค | Canvas 2D สำหรับเครื่องช้า |

FPS เป็นเป้าหมาย ไม่ใช่ผลที่รับประกันบนทุกเครื่อง โหมดต่ำไม่เริ่มโหลด Three.js; ระดับกลาง/โหดโหลดเมื่อเริ่มเล่น ระหว่างโหลดหรือเมื่อ WebGL ใช้ไม่ได้ แอปใช้ Canvas สำรอง

## โครงสร้าง

| ตำแหน่ง | หน้าที่ |
| --- | --- |
| `dist/index.html`, `style.css` | UI และการจัดวาง |
| `dist/app.js` | วงจรแอป กล้อง โหมดตัวอย่าง และการวาด |
| `dist/logic.mjs`, `hand-analysis.mjs`, `temporal.mjs` | ท่าทาง บทบาทมือ และการยืนยันคำสั่ง |

| `dist/geometry.mjs`, `energy-view.mjs`, `crystal-detail.mjs` | รูปทรงและลายผลึก |

## ตรวจโค้ด

ใช้ Node.js 22 ขึ้นไป (CI ใช้ 24) ไม่ต้อง `npm install`

```sh
npm run check
npm test
```

ชุดทดสอบใช้ landmark และ renderer จำลอง จึงไม่แทนการทดสอบมือจริง แสงจริง หรือ GPU ของอุปกรณ์ อ่านรายละเอียดใน [PERFORMANCE.md](docs/PERFORMANCE.md)

## แก้ปัญหา

- กล้องไม่เปิด: ใช้ HTTPS หรือ localhost ตรวจสิทธิ์เว็บไซต์และโปรแกรมอื่นที่ใช้กล้อง
- เปิดจากมือถือผ่าน HTTP ของ IP คอมไม่ได้: ให้ใช้เว็บ HTTPS; LAN IP ไม่ใช่ localhost
- โหลดโมเดลไม่ได้: ตรวจเครือข่ายและการบล็อก jsDelivr / Google Storage
- มือถูกตรวจผิด: จัดแสงให้สม่ำเสมอ ให้มืออยู่เต็มเฟรม ลดการบังกัน และค้างท่าก่อนเปลี่ยน
- GitHub Pages 404: ตรวจ workflow, branch และตำแหน่ง `dist/index.html`
- สลับแท็บแล้วหยุด: เป็นพฤติกรรมตั้งใจเพื่อคืนกล้องและหยุดงานเบื้องหลัง ให้เริ่มเล่นอีกครั้ง
