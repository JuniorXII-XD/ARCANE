# แนวทางดูแล README

ใช้ชื่อไฟล์ `README.md` ที่ราก repository เพื่อให้ GitHub แสดงเป็นหน้าแนะนำอัตโนมัติ

ลำดับที่แนะนำ:
1. ชื่อโปรเจกต์และประโยคเดียวว่าใช้ทำอะไร
2. ภาพหรือคลิปจากโปรเจกต์จริง และลิงก์เดโมเมื่อพร้อมเปิดให้ผู้ชมเข้าถึง
3. ฟีเจอร์หลักที่ทำงานแล้ว
4. วิธีเปิดใช้งานและเผยแพร่ที่ผู้ใช้ทำตามได้
5. ตารางท่าทางควบคุม
6. เทคโนโลยีและโครงสร้างไฟล์
7. วิธีทดสอบ พร้อมข้อจำกัดที่ยังไม่ยืนยัน
8. เครดิตและ LICENSE ที่เจ้าของเลือก

เมื่อใส่พอร์ต ให้เพิ่มหัวข้อ “ปัญหาและวิธีแก้” เช่น การสลับบทบาทมือ การตรวจจับขาดช่วง และการลดงานวาดซ้ำ พร้อมหลักฐานจากผลทดสอบ อย่าใส่ตัวเลขความแม่นหรือ FPS ที่ยังไม่ได้วัด

ภาพแนะนำให้เก็บใน `docs/images/` แล้วอ้างแบบ relative เช่น `![ตัวอย่าง ARCANE](docs/images/demo.png)` จาก README ที่ราก repository เพิ่มภาพจริงก่อนใส่ลิงก์เพื่อไม่ให้รูปเสีย

ชื่อผู้สร้าง/เครดิตในแอปคงข้อความเดิมไว้ เจ้าของสามารถปรับชื่อและเพิ่มช่องทางติดต่อที่ต้องการเปิดเผยก่อนทำ repository เป็นสาธารณะ
